# Структура базы данных Notion

> Последнее обновление: июль 2026

Три связанные таблицы покрывают модули M3 (CRM), M4 (Сессии), M5 (Кабинет клиента), M2 (Оплата) и M7 (Фидбэк).

---

## Таблица: Клиенты (M3 CRM)

| Поле | Тип | Назначение |
|---|---|---|
| Имя | Title | Имя клиента |
| Email | Text | Для писем через Brevo (тип Text, не Email — для совместимости с Make.com) |
| Telegram | Text | Username или номер |
| Telegram Chat ID | Number | Для автоматизации в Make.com |
| Источник | Select | Откуда пришёл клиент |
| Статус | Select | Активный / Завершил / Пауза |
| Сессии | Relation → Сессии | Связь с сессиями клиента |
| Кабинет | Relation → Кабинеты | Связь с кабинетом клиента |
| Теги | Multi-select | Повторный / Рекомендовал / VIP |

---

## Таблица: Сессии (M4 + M2 + M7)

| Поле | Тип | Назначение |
|---|---|---|
| Название | Title | Идентификатор сессии |
| Клиент | Relation → Клиенты | Связь с карточкой клиента |
| Дата | Date | Дата и время сессии |
| Формат | Select | Онлайн / Офлайн |
| Статус | Select | Запланирована / Проведена / Отменена |
| Запрос | Text | Конкретный запрос на эту сессию |
| Сфера | Select | Тема/сфера запроса (по сессии) |
| Приватные заметки | Text | Только для Алины |
| Общие заметки | Text | Видны клиенту в кабинете |
| Домашнее задание | Text | ДЗ после сессии |
| Следующие шаги | Text | План до следующей встречи |
| Booking UID | Text | Уникальный ID брони из Cal.com (для поиска при отмене/переносе) |
| Оплата | Select/Text | Статус оплаты (M2) |
| Оценка | Number | Оценка клиента 1–5 (M7) |
| Обратная связь | Text | Отзыв клиента после сессии (M7) |
| Кабинет | Relation → Кабинеты | Ссылка на кабинет клиента |

---

## Таблица: Кабинеты (M5)

| Поле | Тип | Назначение |
|---|---|---|
| Клиент | Title | Название кабинета (имя клиента) |
| Клиент (связь) | Relation → Клиенты | Связь с карточкой клиента |
| Сессии | Relation → Сессии | Связь с сессиями |
| Ссылка | URL | Magic-link для доступа клиента без пароля |

---

## Связи между таблицами

```
Клиенты ──< Сессии   (один клиент → много сессий)
Клиенты ──1 Кабинеты (один клиент → один кабинет)
Кабинеты ──< Сессии  (кабинет показывает все сессии клиента)
```

---

## Примечания

- Поле **Сфера** в Сессиях хранит тему/запрос на уровне сессии — один клиент может работать с разными темами в разных сессиях. Отдельного поля запроса в Клиентах нет.
- Поле **Теги** в Клиентах — только характеристики клиента, не темы работы.
- Фидбэк (Оценка + Комментарий) хранится прямо в Сессиях, отдельная форма не нужна.
- **Telegram Chat ID** нужен для автоматизации в Make.com (отправка уведомлений).
