# Бэк-офис: план настройки

> **Для выполнения:** пошаговый гайд — выполняй задачи по порядку, каждая зависит от предыдущей.

**Цель:** настроить полноценный бэк-офис на Notion + Make.com + Telegram Bot, подключённый к Cal.com.

**Стек:** Notion (база данных), Cal.com (уже подключён), Make.com (автоматизация), Telegram Bot (уведомления и фидбэк).

---

## Задача 1: Настроить Notion — База «Клиенты»

- [ ] Открой notion.so → войди в свой аккаунт
- [ ] Нажми **+ New page** в левом сайдбаре
- [ ] Выбери тип страницы **Table** (таблица-база данных)
- [ ] Назови страницу: `Клиенты`
- [ ] Удали дефолтные колонки (нажми на заголовок колонки → Delete)
- [ ] Добавь следующие колонки (кнопка **+** справа от таблицы):

| Название поля | Тип поля |
|---|---|
| Имя | Title (уже есть по умолчанию) |
| Email | Email |
| Telegram | Text |
| Telegram Chat ID | Number |
| Источник | Select → добавь варианты: Instagram, Telegram, Рекомендация, Лендинг, Другое |
| Статус | Select → добавь варианты: Активный, Пауза, Завершён |

- [ ] Проверь: таблица должна иметь 6 колонок
- [ ] Нажми **Share** (вверху справа) → убедись что доступ **Private** (не публичный)

---

## Задача 2: Настроить Notion — База «Сессии»

- [ ] Создай новую страницу: **+ New page** → **Table**
- [ ] Назови: `Сессии`
- [ ] Настрой колонки:

| Название поля | Тип поля |
|---|---|
| Название | Title (по умолчанию) |
| Клиент | Relation → выбери базу **Клиенты** |
| Дата | Date (включи время: Date with time) |
| Формат | Select → Онлайн, Офлайн |
| Статус | Select → Запланирована, Проведена, Отменена |
| Запрос | Text |
| Сфера | Select → Отношения, Финансы, Здоровье, Самооценка, Реализация, Семейные сценарии, Другое |
| Приватные заметки | Text |
| Общие заметки | Text |
| Домашнее задание | Text |
| Next steps | Text |
| Оплата | Select → Ожидает, Получена |
| Фидбэк — оценка | Number |
| Фидбэк — комментарий | Text |

- [ ] Проверь связь: в колонке **Клиент** нажми на любую ячейку → должен открыться выбор из базы Клиенты

## Задача 3: Настроить Notion — Кабинеты клиентов

- [ ] Создай новую страницу: **+ New page** → выбери **Page** (обычная страница, не таблица)
- [ ] Назови: `Кабинеты клиентов`
- [ ] Внутри страницы создай новую таблицу: **/ → Table**
- [ ] Назови таблицу: `Кабинеты`
- [ ] Настрой колонки:

| Название поля | Тип поля |
|---|---|
| Клиент | Title |
| Ссылка на клиента | Relation → база **Клиенты** |
| Сессии (запросы) | Rollup → поле Relation: Клиент в базе Сессии → поле: Запрос → функция: Show original |
| Сессии (общие заметки) | Rollup → поле Relation: Клиент в базе Сессии → поле: Общие заметки → функция: Show original |

- [ ] Проверь: создай тестовую запись в Клиенты, затем запись в Сессии с этим клиентом — убедись что данные появляются в Кабинетах

## Задача 4: Создать Telegram-бота

- [ ] Открой Telegram → найди бота **@BotFather**
- [ ] Отправь команду `/newbot`
- [ ] BotFather спросит имя бота (отображается в чате) → напиши: `Алина Шведова — терапия`
- [ ] BotFather спросит username бота (уникальный, заканчивается на bot) → напиши, например: `alina_therapy_bot`
- [ ] Если username занят — добавь цифры: `alina_therapy_2026_bot`
- [ ] BotFather выдаст **токен** вида `7123456789:AAFxxxxxxx` → скопируй и сохрани в заметки, он понадобится в Make.com
- [ ] Отправь боту `/start` — убедись что он запустился (может не отвечать, это нормально пока)
- [ ] Узнай свой личный **Chat ID**: найди бота **@userinfobot** → отправь ему `/start` → он пришлёт твой Chat ID → сохрани его в заметки

## Задача 5: Зарегистрироваться в Make.com и подключить сервисы

- [ ] Открой make.com → зарегистрируйся (можно через Google)
- [ ] После входа попадёшь на Dashboard → нажми **Create a new scenario**
- [ ] Подключи Notion:
  - Нажми **+** в сценарии → найди **Notion** → выбери любой модуль
  - Нажми **Add** рядом с Connection → **Connect with Notion**
  - Авторизуйся через свой Google аккаунт Notion
  - Выбери доступ ко всем страницам → **Allow access**
- [ ] Подключи Telegram:
  - Нажми **+** → найди **Telegram Bot** → выбери любой модуль
  - Нажми **Add** → вставь токен бота из Задачи 4
  - Нажми **Save**
- [ ] Закрой этот тестовый сценарий (не сохраняй) — он был только для подключения аккаунтов

## Задача 6: Make.com — Сценарий 1 «Новая запись Cal.com»

**Что делает:** Cal.com → создаёт/находит клиента в Notion → создаёт сессию → пишет клиенту и Алине в Telegram.

- [ ] Создай новый сценарий: **Create a new scenario**
- [ ] Назови сценарий: `1 — Новая запись Cal.com`

**Шаг 1 — Триггер Cal.com:**
- [ ] Нажми **+** → найди **Webhooks** → выбери **Custom webhook**
- [ ] Нажми **Add** → назови `cal-booking` → скопируй URL вебхука
- [ ] Перейди в Cal.com → Settings → Webhooks → Add webhook → вставь URL → выбери событие **BOOKING_CREATED** → Save
- [ ] Вернись в Make → нажми **OK** → сделай тестовую запись в Cal.com чтобы Make получил структуру данных

**Шаг 2 — Поиск клиента в Notion:**
- [ ] Добавь модуль **Notion → Search Objects**
- [ ] Database: выбери **Клиенты**
- [ ] Filter: Email = `{{1.payload.attendees[].email}}` (из данных вебхука)

**Шаг 3 — Создание клиента если не найден:**
- [ ] Добавь **Router** (разветвление) после поиска
- [ ] Ветка 1 (клиент не найден): добавь **Notion → Create a Database Item**
  - Database: **Клиенты**
  - Имя: `{{1.payload.attendees[].name}}`
  - Email: `{{1.payload.attendees[].email}}`
- [ ] Ветка 2 (клиент найден): пустая (продолжает с найденным клиентом)

**Шаг 4 — Создание сессии:**
- [ ] Добавь **Notion → Create a Database Item**
- [ ] Database: **Сессии**
- [ ] Название: `{{attendee name}} — {{date}}`
- [ ] Клиент: ID клиента из шага 2 или 3
- [ ] Дата: `{{1.payload.startTime}}`
- [ ] Статус: `Запланирована`
- [ ] Формат: `Онлайн` (по умолчанию, можно изменить вручную)

**Шаг 5 — Сообщение клиенту:**
- [ ] Добавь **Telegram Bot → Send a Text Message**
- [ ] Chat ID: Telegram Chat ID клиента из Notion (поле из базы Клиенты)
- [ ] Text:
```
Привет, {{имя}}! 👋

Сессия записана на {{дата}} в {{время}}.
Если нужно перенести — напиши не позднее чем за 24 часа.

До встречи 🙏
```
- [ ] Добавь условие: если Chat ID пустой — пропустить этот шаг (клиент ещё не написал боту)

**Шаг 6 — Уведомление Алине:**
- [ ] Добавь ещё один **Telegram Bot → Send a Text Message**
- [ ] Chat ID: вставь свой личный Chat ID из Задачи 4
- [ ] Text:
```
📅 Новая запись!
Клиент: {{имя}}
Дата: {{дата}} в {{время}}
```
- [ ] Нажми **Save** → включи сценарий (переключатель внизу → ON)
- [ ] Проверь: сделай тестовую запись в Cal.com → убедись что в Notion появилась сессия и ты получила уведомление в Telegram

## Задача 7: Make.com — Сценарий 2 «Напоминание за 24 часа»

**Что делает:** каждый час проверяет сессии на завтра → шлёт напоминание клиенту и Алине.

- [ ] Создай новый сценарий: `2 — Напоминание за 24ч`
- [ ] Триггер: **Schedule** → каждые 60 минут

**Поиск завтрашних сессий:**
- [ ] Добавь **Notion → Search Objects**
- [ ] Database: **Сессии**
- [ ] Filter 1: Статус = `Запланирована`
- [ ] Filter 2: Дата = Tomorrow (завтрашняя дата)

**Напоминание клиенту:**
- [ ] Добавь **Iterator** (разворачивает список найденных сессий)
- [ ] Добавь **Telegram Bot → Send a Text Message**
- [ ] Chat ID: Chat ID клиента из связанной базы Клиенты
- [ ] Text:
```
Напоминаю: завтра у нас сессия в {{время}}. 
Жду тебя! 🌿
```

**Напоминание Алине:**
- [ ] Добавь **Telegram Bot → Send a Text Message**
- [ ] Chat ID: твой личный Chat ID
- [ ] Text:
```
⏰ Напоминание: завтра сессия с {{имя клиента}} в {{время}}
```
- [ ] Сохрани → включи сценарий (ON)
- [ ] Проверь: создай тестовую сессию с датой = завтра → запусти сценарий вручную (Run once) → убедись что пришли напоминания

## Задача 8: Make.com — Сценарий 3 «Фидбэк после сессии»

**Что делает:** когда Алина меняет статус сессии на «Проведена» → бот запрашивает фидбэк у клиента → сохраняет в Notion.

**Часть A — Запуск диалога фидбэка:**
- [ ] Создай новый сценарий: `3 — Фидбэк после сессии`
- [ ] Триггер: **Notion → Watch Database Items** → Database: **Сессии**
- [ ] Добавь **Filter**: Статус = `Проведена`
- [ ] Добавь **Telegram Bot → Send a Text Message**
- [ ] Chat ID: Chat ID клиента
- [ ] Text:
```
Спасибо за сегодняшнюю сессию! 🙏
Оцени, пожалуйста, от 1 до 5 — как прошло?
```
- [ ] Сохрани ID сессии в переменную (понадобится для записи фидбэка)

**Часть B — Получение оценки:**
- [ ] Создай отдельный сценарий: `3b — Получение фидбэка`
- [ ] Триггер: **Telegram Bot → Watch Updates**
- [ ] Добавь **Filter**: сообщение содержит только цифру 1–5 (regex: `^[1-5]$`)
- [ ] Добавь **Notion → Update a Database Item**
  - Database: **Сессии**
  - Найди нужную сессию по Chat ID клиента + статус «Проведена»
  - Поле **Фидбэк — оценка** = значение сообщения
- [ ] Добавь **Telegram Bot → Send a Text Message**
- [ ] Text: `Спасибо! Есть комментарий или пожелание? (или отправь /skip)`

**Часть C — Получение комментария:**
- [ ] Добавь ещё один **Filter** в сценарий 3b: сообщение НЕ равно `/skip`
- [ ] Добавь **Notion → Update a Database Item**
  - Поле **Фидбэк — комментарий** = текст сообщения
- [ ] Добавь **Telegram Bot → Send a Text Message**
- [ ] Text: `Записала, спасибо! До следующей сессии 🌿`
- [ ] Включи оба сценария (ON)
- [ ] Проверь: смени статус тестовой сессии на «Проведена» → убедись что бот написал запрос → ответь цифрой → убедись что оценка записалась в Notion

## Задача 9: Регистрация клиентов в боте

**Что делает:** чтобы бот мог писать клиентам, каждый должен написать ему первым.

- [ ] Скопируй ссылку на бота: `t.me/alina_therapy_bot` (замени на свой username)
- [ ] Отправь каждому существующему клиенту сообщение:
```
Привет! Я настроила Telegram-бота для удобного общения.
Напиши ему /start, чтобы получать напоминания о сессиях: t.me/alina_therapy_bot
```
- [ ] Когда клиент пишет `/start` → Make.com автоматически сохраняет его Chat ID в Notion
- [ ] Проверь в Notion: открой карточку клиента → поле **Telegram Chat ID** должно заполниться

- [ ] Открой свою Excel-таблицу

## Итог

После выполнения всех задач система работает так:
1. Клиент записывается в Cal.com → ты и клиент получают уведомление в Telegram + сессия создаётся в Notion
2. За 24ч → автоматическое напоминание клиенту и тебе
3. Ты провела сессию → меняешь статус на «Проведена» → бот запрашивает фидбэк у клиента → оценка и комментарий сохраняются в Notion
4. Кабинет клиента: шаришь страницу Notion тем, кому нужен доступ
