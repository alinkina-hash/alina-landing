# Дизайн бэк-офиса: Алина Шведова — Вселенская терапия

**Дата:** 24 июня 2026  
**Статус:** Согласован

---

## Цель

Заменить Excel-таблицу полноценным бэк-офисом: вести клиентов, сессии, заметки, домашку и автоматически отправлять уведомления и запрашивать фидбэк через Telegram.

---

## Стек

| Инструмент | Роль |
|---|---|
| **Notion** | База данных: клиенты, сессии, заметки, домашка, фидбэк |
| **Cal.com** | Бронирование сессий (уже подключён к лендингу) |
| **Make.com** | Автоматизация всех сценариев |
| **Telegram Bot** | Уведомления клиентам + сбор фидбэка в чате |

---

## Архитектура данных в Notion

### База 1 — Клиенты

| Поле | Тип | Описание |
|---|---|---|
| Имя | Заголовок | Имя клиента |
| Telegram | Текст | @username или телефон |
| Telegram Chat ID | Число | Для отправки сообщений через бота |
| Email | Email | Из Cal.com, используется как уникальный ключ |
| Источник | Select | Instagram / Telegram / Рекомендация / Лендинг / Другое |
| Статус | Select | Активный / Пауза / Завершён |
| Кабинет | Связь | Ссылка на страницу кабинета клиента |

### База 2 — Сессии

| Поле | Тип | Описание |
|---|---|---|
| Название | Заголовок | Авто: «Имя клиента — дата» |
| Клиент | Связь | Связь с базой Клиенты |
| Дата | Дата + время | Дата и время сессии |
| Формат | Select | Онлайн / Офлайн |
| Статус | Select | Запланирована / Проведена / Отменена |
| Запрос | Текст | С чем пришёл клиент на эту конкретную сессию |
| Сфера | Select | Отношения / Финансы / Здоровье / Самооценка / Реализация / Семейные сценарии / Другое |
| Приватные заметки | Текст | Только для Алины, не передаётся клиенту |
| Общие заметки | Текст | Можно показать клиенту |
| Домашнее задание | Текст | ДЗ после сессии |
| Next steps | Текст | Следующие шаги |
| Оплата | Select | Ожидает / Получена |
| Фидбэк — оценка | Число | 1–5, заполняется автоматически из Telegram |
| Фидбэк — комментарий | Текст | Заполняется автоматически из Telegram |

### База 3 — Кабинеты клиентов

Отдельная страница в Notion на каждого клиента. Содержит:
- Общие заметки из сессий (связанная база)
- Домашние задания
- Next steps

Доступ: Алина шарит страницу конкретному клиенту как гость Notion (до 10 гостей на бесплатном плане). Клиент видит только свою страницу.

## Сценарии автоматизации (Make.com)

### Сценарий 1 — Новая запись через Cal.com

**Триггер:** Cal.com отправляет вебхук при новом бронировании.

**Действия:**
1. Make ищет клиента в Notion по email
2. Если клиент не найден — создаёт новую карточку с именем и email
3. Создаёт запись в базе Сессии: клиент, дата, формат, статус «Запланирована»
4. Telegram-бот отправляет клиенту подтверждение:  
   *«Привет, [Имя]! Сессия записана на [дата] в [время]. Если нужно перенести — напиши не позднее чем за 24 часа. До встречи 🙏»*

> Клиент получает Chat ID в момент, когда первый раз пишет боту `/start`. Make.com сохраняет Chat ID в карточку клиента в Notion.

### Сценарий 2 — Напоминание за 24 часа

**Триггер:** Make.com проверяет базу Сессии каждый час, ищет сессии со статусом «Запланирована» и датой = завтра.

**Действия:**
1. Telegram-бот отправляет клиенту напоминание:  
   *«Напоминаю: завтра у нас сессия в [время]. Жду тебя 🌿»*

### Сценарий 3 — Запрос фидбэка после сессии

**Триггер:** Алина меняет статус сессии на «Проведена» в Notion.

**Действия:**
1. Make замечает изменение статуса
2. Telegram-бот отправляет клиенту:  
   *«Спасибо за сегодняшнюю сессию! Оцени, пожалуйста, от 1 до 5 🙏»*
3. Клиент отвечает цифрой — Make сохраняет оценку в Notion
4. Бот отвечает: *«Спасибо! Есть комментарий или пожелание?»*
5. Клиент пишет комментарий (или `/skip`) — Make сохраняет в Notion

---

## Telegram Bot: регистрация клиента

Чтобы бот мог писать клиенту, клиент должен написать боту первым.

**Процесс:**
1. Алина создаёт бота через @BotFather (5 минут)
2. При записи нового клиента — Алина отправляет ему ссылку на бота в Telegram
3. Клиент пишет `/start` — бот отвечает приветствием и сохраняет Chat ID
4. Make.com записывает Chat ID в карточку клиента в Notion

---

## Кабинет клиента

- Страница в Notion на каждого клиента
- Содержит: общие заметки, домашку, next steps из всех сессий
- Алина шарит страницу вручную тем клиентам, которым нужен доступ
- Клиент заходит по ссылке без пароля (Notion guest access)

## Ограничения бесплатных планов

| Сервис | Лимит | При текущем масштабе |
|---|---|---|
| Notion | До 10 гостей | Хватит для начала |
| Make.com | 1 000 операций/месяц | ~30–40 сессий = ~200 операций/месяц, запас x5 |
| Telegram Bot | Без лимитов | — |

## Порядок настройки

1. Создать аккаунт Notion, настроить три базы данных
2. Создать Telegram-бота через @BotFather
3. Создать аккаунт Make.com
4. Настроить Сценарий 1 (Cal.com → Notion + Telegram)
5. Настроить Сценарий 2 (напоминание за 24ч)
6. Настроить Сценарий 3 (фидбэк после сессии)
7. Перенести существующих клиентов из Excel в Notion
8. Попросить клиентов написать боту `/start`
